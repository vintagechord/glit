# 내 음악 관리 국내 검색 및 실제 앨범 가져오기

2026-09-08. 이 문서는 기존 `music-archive.md`의 제공처·화면 설명을 보완한다.

## 회원 기능

- 기본 검색은 실제 Apple Music 한국 카탈로그의 아티스트 후보다. MusicBrainz·Spotify는 새 연결 선택지에서 제외했다. 사용할 수 없는 제공처 카드나 계약·서버 설정 안내를 회원 화면에 표시하지 않는다.
- 이름 검색은 문서화된 iTunes Search API를 사용한다. 한 번 얻은 최대 200개 후보를 15분 캐시하고 20개씩 표시한다. 한국 이름·영문명·장르·정확한 제공처 ID를 보존하며 첫 후보를 임의 연결하지 않는다.
- 초성 제안은 공개 API에서 실제 확인된 아티스트의 이름·별칭 인덱스를 사용한다. 회원이 직접 입력한 이름과 비공개 심의 내역을 전역 인덱스로 보내지 않는다. 국내 전체 아티스트 명부가 아니며, 제안에 없는 이름은 전체 이름으로 카탈로그 검색한다.
- 기존 멜론 연결은 주소만 저장하던 구현이었다. 기존 링크는 보존하고 **앨범 찾아보기 → 실제 후보 선택 → 확인**으로 이용 가능한 카탈로그에서 앨범·트랙을 가져온다. 멜론 ID를 Apple ID로 임의 변환하거나 동명이인을 자동 병합하지 않는다.
- 연결 확인 시 서버가 ID를 다시 검증하고 수집 작업을 등록한다. 연결이 저장된 뒤 수집 등록에 실패해도 저장 성공과 재시도 안내를 반환해 중복 아티스트 생성과 열린 모달 재접수를 방지한다.
- 수집 진행/개수는 아티스트 상세에서 바로 보인다. 완료·수정·제외·기존 심의 연결은 그대로 유지하며, 외부 정보의 변경은 충돌 후보로 남긴다. Apple 트랙 ID를 녹음 ID·ISRC·저작물 ID로 사용하지 않는다.
- KOMCA·KOSCAP은 실제 공식 검색 URL과 작품명/저작자 복사, 회원 확인 후 업무 기록 흐름을 제공한다. 자동 저작자 정보 수집을 제공하는 것은 아니다. 한국저작권위원회 키 기반 어댑터는 별도 코드로 준비되어 있고 키 없는 상태에서 회원 기능으로 노출하지 않는다.

## 실제 데이터 범위

[Apple API 조사/검증](music-archive-apple.md), [멜론 확인](music-archive-melon.md), [협회 및 위원회 확인](music-archive-copyright.md).

한국 storefront는 아티스트·앨범 목록을 제공하지만 실증 시 트랙 행을 반환하지 않았다. 동일한 album ID의 미국 storefront에서 곡 정보를 확인한다. 앨범의 명시된 곡 수와 응답 수가 일치해야 그 앨범을 저장한다. 공식 artist-song ID 목록에 있는 협업곡만 추가 관리 대상으로 인정한다. 한도(200개), 누락, 중단은 부분 상태이며 전곡 100% 확인으로 바꾸지 않는다. 음원·가사·사진·앨범 커버는 가져오지 않는다.

## 운영 구조

추가 마이그레이션 `0099_music_archive_domestic_catalog.sql`:

- 기존 sources/jobs/호출 제한에서 Apple 제공처를 추가 허용한다.
- Apple의 모든 서버 검색/수집을 DB 공유 슬롯 3.1초 간격(분당 약 19회)으로 제한한다.
- 서비스 역할만 접근할 수 있는 공개 아티스트 초성 인덱스와 검색 캐시를 추가한다. 기존 회원·심의·결제 테이블을 바꾸거나 고객 문서를 초기화하지 않는다.

POST 응답 뒤 `after()`가 바로 처리하고, 아티스트 상세 조회도 미완료 작업을 이어 처리한다. Render의 `npm run start`로 시작한 운영 Node 서버에는 같은 DB 작업 큐를 처리하는 dispatcher가 실행된다. 프로세스별 중복 실행을 막고, DB lease/원자적 커서 저장으로 요청과 워커의 중복 처리를 방지한다. 별도의 유료 워커를 만들지 않는다. 무료 웹 서버가 정지/휴면 중이면 처리는 멈추며 다음 서버 시작 때 큐를 재개한다. `MUSIC_ARCHIVE_WORKER_DISABLED=true`는 운영 dispatcher를 중지하는 서버 옵션이다. 빌드·개발 서버·외부 런타임에서는 자동 실행하지 않는다.

## 검증 구분

- 실제 외부 HTTP: `빈티지코드`의 서로 다른 두 후보 반환. ID 1259084205는 9단계에서 앨범 7개·트랙 26개 완료, 협업 2개 앨범 포함. 다른 후보 1112117967은 앨범 2개 확인. 해당 아티스트가 기존 회원과 같은 사람이라는 판단은 테스트하지 않는다.
- 모의 외부 응답: ID/URL 검증, 429/잘린 응답/200개 제한, 커서 재개, 검색 캐시와 소유권·연결 저장 실패 회복 검증.
- 로컬 PostgreSQL: 기존 개인자료 격리·lease/낙관적 버전 검증 및 0099 제공처 분리·전역 호출 간격·초성 인덱스·캐시 접근권한 검증.
- 격리 브라우저: 실제 React 컴포넌트에 API 응답 fixture를 넣어 이름/초성 선택, 모달과 재시도, 폴링 중 편집 유지, 공식 검색의 업무 상태 불변을 검증. 운영 로그인 우회는 추가하지 않았다.
- 빌드/TypeScript/변경 범위 ESLint와 기존 아카이브 테스트를 실행한다. 실제 운영 배포와 DB 적용 결과는 배포 후 아래에 기록한다.
