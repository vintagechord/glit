## 결제

일반결제에 빠져 있던 `use_chkfake`, `centerCd`, 승인 요청 `verification`을 추가했다. 인증 토큰의 줄바꿈·공백 원문을 보존하고 IDC·환경에 맞는 승인/망취소 주소만 사용한다. 승인 응답의 가맹점, 주문, 금액, 통화, 결제수단, 거래번호와 승인일시를 검증한다. 응답 시간·크기를 제한하고 중복 필드와 잘못된 인코딩을 거절한다.

공식 응답에 필수가 아닌 `authSignature` 때문에 정상 결제 후 비회원 결과 접근권이 발급되지 않던 문제를 수정했다. 중복 승인 방지와 결과 미확정 거래 잠금은 유지했다. 망취소는 HTTP 상태만으로 성공 처리하지 않는다.

**모바일 카드 결제는 활성화되지 않았다.** 현재 구현은 PC STDPay이며 확인한 로컬 설정에는 온사이드 모바일 일반결제용 HashKey가 없다. 모바일·iPad에서는 PC 결제창과 카드 주문 생성을 막고 무통장 입금을 기본 선택한다. PC에서 카드 결제할 수 있다는 안내를 제공한다. 모바일 전용 연동에는 온사이드 가맹점의 계약·키 확인과 별도 승인/취소 흐름 구현 및 PG 검증이 필요하다.

사용자는 모바일 키의 발급 여부를 확인해야 한다고 답했다. 발급 확인 전에는 위 모바일 무통장/PC 카드 안내를 유지한다.

## 신청서·음원·영상 업로드

- 미발매 음반에서 건너뛰던 작성 방식 선택을 복구하여 ‘파일로 제출’에 접근할 수 있다. 발매 음반 URL 접수는 기존 경로를 유지한다.
- 분할 업로드 URL이 만료되면 새 주소를 받아 재시도한다.
- 브라우저 저장소 차단·오염·만료 때문에 성공한 업로드가 실패로 바뀌지 않는다.
- 실패한 파일을 다시 올릴 수 있고, 기존 작업이 끝나기 전 새 재시도가 경쟁하지 않도록 했다.
- 업로드 중 첨부 삭제를 막아 늦은 응답이 삭제 파일을 되살리지 않도록 했다.
- 빈 파일과 거부된 파일의 이유를 안내하고, 영상 최대 용량 표기를 실제 설정과 맞췄다.

운영 B2에 HEAD 및 업로드 CORS 사전 요청을 보내 정상 응답과 ETag 노출을 확인했다. 실제 운영 파일을 업로드하거나 삭제하지 않았다. 브라우저 테스트는 네트워크 쓰기를 모의 처리했다. DOCX+WAV, DOCX+영상, 실패/정지 복구, 33MB 음원 ZIP과 129MB 영상의 분할 전송을 검증했다. 4GB 한계 용량의 실전송은 실행하지 않았다.

## 관리자 결과와 의뢰자 표시

상태·메모·곡별 결과를 한 SQL 쓰기로 저장한다. 잘못된 트랙 ID·중복·형식 오류는 저장하지 않는다. 일부 곡만 판정된 경우와 보완요청을 완료로 집계하지 않는다. 과거 전체 결과와 곡별 결과를 일관되게 표시하며, 원음방송의 대상곡 제한을 별도로 처리한다.

원음방송에서 4곡 이상 앨범의 대상곡이 기록되지 않았다면 전체 적격 상태만으로 모든 곡을 승인하지 않는다. 현재 곡 ID에 대응하는 실제 3곡 결과가 있으면 그 곡들로 완료를 판단한다. 4곡 이상을 최종 판정하는 새 저장은 차단한다. 원음방송 신청서도 고객이 선택한 곡을 타이틀 우선 기본값보다 먼저 사용한다.

회원 초기 화면에서 실제 방송국 결과가 누락되던 문제를 수정했다. 적격 결과의 메모와 전체 결과 메모도 의뢰자에게 표시한다. 실시간 변경 수신이 누락되면 화면 복귀 또는 15초 간격 조회로 복구한다. 알림 요약에도 화면과 같은 부분 적격/심의중 판정을 사용한다. 완료 화면의 중복 진행표와 단계 표시를 줄였다.

관리자 실제 폼 → 저장 helper → 의뢰자 실제 컴포넌트를 브라우저에서 연결하되 DB와 실시간 이벤트는 모의 처리했다. 부분 결과, 전체 적격, 보완요청, 저장 실패, 화면 복귀 갱신을 확인했다.

## 무료 라디오 신청곡 지원

심의 완료 화면과 결과 전용 화면에 다음 기능을 추가했다.

- 해당 방송국에서 적격인 곡 선택
- 신청곡 제목·사연 편집, 각각 복사, 텍스트 초안 저장
- 방송국·곡을 바꿨다 돌아와도 현재 화면의 편집 초안 유지
- 공식 라디오 페이지에서 프로그램과 참여 게시판을 찾는 링크
- 프로그램 선택 → 로그인·공지 확인 → 문구 작성 → 직접 등록 → 게시글·선곡표 확인 안내
- 준비 체크리스트, 곡 정보·크레딧/방송국별 결과 CSV/가이드 ZIP 다운로드

외부 자동 게시, 추가 결제, 유료 API 호출은 없다. 신청곡 등록과 실제 방송 편성은 구분해 안내한다. ZIP은 참고용 텍스트 자료이며 원본 음원·영상·증명서는 포함하지 않는다. 확인되지 않은 방송국에는 다른 방송국이나 검색엔진을 대신 연결하지 않는다. 영문 화면, 모바일 표시, 복사 권한 차단 시 수동 복사도 지원한다.

공식 링크 확인: [KBS](https://radio.kbs.co.kr/), [MBC](https://m.imbc.com/RadioMain), [SBS](https://radio.sbs.co.kr/), [CBS](https://www.cbs.co.kr/radio), [BBS](https://www.bbs.or.kr/HOME2/?ACT=RADIO), [국악방송](https://new.igbf.kr/) 등. 개별 프로그램 종료에 따른 오연결을 줄이기 위해 현재 프로그램 목록으로 안내한다.
