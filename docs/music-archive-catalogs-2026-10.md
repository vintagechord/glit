# 아티스트 검색·발매 이력 연결 (2026-10-27)

이 문서는 기존 `music-archive-providers.md`의 2026-09 시점 제공처 상태를 갱신한다.

## 회원 사용 흐름

1. 내 음악 관리 → 아티스트 추가 → 멜론, 지니뮤직, Spotify, YouTube 채널, Apple Music 중 검색할 서비스를 선택하고 활동명을 입력한다.
2. 동명이인은 제공처·아티스트 ID와 공식 프로필을 열어 구분한 다음 본인 아티스트를 선택한다. 제공처 간 동일 이름을 자동 병합하지 않는다.
3. 멜론·지니·Apple Music과 API가 연결된 Spotify는 해당 아티스트 ID의 앨범·수록곡을 백그라운드에서 불러온다. 중단 시 다시 불러오기로 저장된 지점부터 이어간다. YouTube는 채널 연결만 제공하며 영상·재생목록 게시일을 앨범 발매일로 간주하지 않는다.
4. 기존 온사이드 신청은 정확한 앨범 URL/저장한 신청 범위에 따라 연결한다. 일부 곡만 심의된 앨범에는 남은 곡별 신청 버튼을 표시한다. 진행 중 신청은 상세 페이지에서 결제·자료 보완·결과를 확인한다. 완료된 곡은 ‘다른 방송사 심의 신청’에서 아직 신청하지 않은 방송사를 선택할 수 있으며, 진행 중인 곡에는 중복 신청을 권하지 않는다.
5. 외부에서 완료한 심의는 심의 내역 입력으로 기록한다. 공개 음원 사이트의 데이터만으로 심의 완료나 미완료를 단정하지 않는다.

## 구현과 설정

- `domestic-catalog.ts`: 실제 공개 멜론·지니 검색 화면의 결과 컨테이너만 읽는다. 아티스트 선택 뒤 고정된 공식 호스트·경로에서 식별자로 요청을 구성한다. 리다이렉트 거부, 12초 HTTP 제한, 3 MB 응답 제한, 전체 인스턴스 공유 호출 간격을 적용한다.
- 수집 단계마다 앨범 목록 한 페이지 또는 앨범 상세 한 페이지를 처리한다. 멜론 공개 `albumPaging.htm`의 `startIndex/pageSize`, 지니 화면이 호출하는 `bArtistAlbumList`의 읽기용 POST 파라미터를 사용한다. 새 발매작을 찾으려면 다시 불러오기를 실행한다.
- 원본 곡 행 수와 파싱된 곡 수가 다르거나 선택 아티스트의 정확한 트랙 ID 관계를 확인하지 못하면 완료로 처리하지 않는다. 타 아티스트 곡은 자동 관리 대상에서 제외한다. 같은 제목의 다른 버전은 합치지 않는다.
- 지니 상세 페이지에서 앨범 종류를 제공하지 않으면 `기타`로 남긴다. 가사·음원·영상·이미지 파일은 수집하지 않고 공식 썸네일 URL만 표시한다.
- Spotify: 서버의 `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`으로 공식 API를 사용한다. YouTube: `YOUTUBE_DATA_API_KEY`로 공식 채널 검색/조회만 수행한다. 키가 없으면 구성 필요 안내와 공식 사이트의 텍스트 검색 링크를 제공한다. 키는 클라이언트 응답에 포함하지 않는다.
- Apple 검색 캐시·초성 인덱스는 보조 자료다. 캐시/인덱스 쓰기 실패 때문에 정상 공개 검색이나 검증된 아티스트 연결을 실패시키지 않는다. 초성 검색 자체는 기존 공개 인덱스 범위에서만 가능하다.
- `supabase/migrations/20261026150859_music_archive_more_catalogs.sql`은 2026-10-27 운영 적용했다. 전후 스키마·이력 비교에서 기존 owner RLS와 service-role 전용 큐/슬롯 권한 보존 및 검토한 제공처 제약만 확장됨을 확인했다. YouTube는 발매 앨범 동기화 큐에 추가하지 않는다.
- 사용자 요청으로 Spotify·YouTube API 키 발급·등록·활성화는 보류한다. 사용자가 재개를 요청하면 진행하며, 다른 제공처와 심의 관리의 운영 반영을 막지 않는다.

## 검증 범위

2026-10-27 읽기 전용 HTTP로 다음 공개 페이지와 실제 ID/곡 연결을 확인했다. 회원 데이터에 쓰지 않았다.

- [멜론 아티스트 검색](https://www.melon.com/search/artist/index.htm?q=%EC%95%84%EC%9D%B4%EC%9C%A0), [아티스트 앨범](https://www.melon.com/artist/album.htm?artistId=261143), [샘플 앨범](https://www.melon.com/album/detail.htm?albumId=12106743)
- [지니 아티스트 검색](https://www.genie.co.kr/search/searchArtist?query=%EC%95%84%EC%9D%B4%EC%9C%A0), [아티스트 앨범](https://www.genie.co.kr/detail/artistAlbum?xxnm=67872918), [샘플 앨범](https://www.genie.co.kr/detail/albumInfo?axnm=88135998)
- Spotify/YouTube 공식 API 동작은 모의 응답 테스트로 검증했다. 실제 자격증명과 운영 앱 접근 범위는 별도로 설정해야 한다.
- 격리된 PostgreSQL 17에서 새 제공처 마이그레이션과 기존·신규 SQL 통합 테스트를 통과했다. 운영 DB에는 적용하지 않았다.
- 음악 아카이브 Chromium 테스트 18개와 최종 제공처/부분심의 동작 재검증을 통과했다.
- `tests/music-archive-domestic-catalog.test.ts`는 동명이인, 추천 위젯 제외, 중첩 목록, ID 접두사 충돌, 일부 트랙 누락, 혼합 아티스트, 잘못된 커서, 재시도와 부분 심의 신청 범위를 검증한다.

멜론·지니는 공개 웹 화면을 이용하므로 사이트 구조 변경·접근 제한으로 조회가 실패할 수 있다. 이 경우 기존 기록과 커서를 유지하고 공식 사이트/직접 등록을 이용한다. 조회 완료는 해당 서비스의 공개 목록 처리 완료를 뜻하며 모든 과거 발매작을 보장하는 표시는 아니다.
